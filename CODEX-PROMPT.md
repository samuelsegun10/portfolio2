# Focused Codex request

Use your own available Codex client. Open the extracted starter locally, or open your repository if your account offers repository access. Free-plan availability and usage limits can vary. A manual route is in MANUAL-EDITING.md.

Replace the angle-bracket items, then send this request to Codex:

```text
This is my student portfolio starter. Read README.md and content/portfolio.json. My already documented public project is at <PROJECT-GITHUB-URL>. Use only information you can verify in that repository or facts I give you. If you cannot access it, ask me to paste its README before writing project claims.

Personalize content/portfolio.json for me:
- Public name: <NAME>
- Honest current or learning-stage title: <TITLE>
- Short introduction and About text based on my real work
- One project card with its real title, tools/category, concise question-method-finding summary, and public URL
- My chosen contact links: <LINKS OR NONE>

Leave Samples and Insights empty unless I provide real public-safe items. Do not fabricate experience, metrics, outcomes, testimonials, or links. Do not change layout, theme code or deployment settings. Do not attempt CMS or OAuth setup. Check that the JSON parses and local paths still work, then tell me exactly which files changed and what I should review before publishing.
```

Keep the task small. If you hit a usage limit, save the work and use MANUAL-EDITING.md. You do not need to buy a plan to try the manual route.
