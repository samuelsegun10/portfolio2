# Student Portfolio Starter 1.3.1

A self-service static portfolio. Download it, put the website files in a GitHub repository you own, add your real work, and publish with GitHub Pages. No worksheet, instructor handoff, Node installation, Cloudflare account, or CMS setup is required for the basic website.

Begin with START-HERE.md. The content you edit is in content/portfolio.json. Your own Codex account may help you personalize it; MANUAL-EDITING.md gives a fallback if Codex is unavailable.

The site includes Home, About, Projects and Contact pages, plus optional Samples and Insights pages. Samples can show any permitted work artifact relevant to your goals; their navigation link appears only when you add samples. The dark/light theme switch works across pages.

CMS sign-in is not active in this package. See CMS-LATER.md before considering it. Do not add OAuth secrets to this repository.

This website has no links to the template creator's profile. Retain THIRD-PARTY-NOTICES.md and source attribution.
