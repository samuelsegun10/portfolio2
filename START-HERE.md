# Start here — publish your own portfolio

You can complete this without sending your details to an instructor.

## 1. Put the files in your own repository

Create or open a public GitHub repository you own. Download and unzip this starter. On your repository's Code page, use Add file > Upload files (or the empty-repository upload link). Upload the **contents** of this starter folder, not the outer folder or ZIP. Check that index.html, content/, assets/, images/, about/, contact/, projects/, samples/ and insights/ appear at the repository root.

## 2. Add your real work

Open content/portfolio.json. Replace Your Name, the learning-stage title, introduction and About text. Add one project you already documented, using its real title, a short question-method-finding summary, and its public GitHub project URL. Use a screenshot only when you have permission to publish it. Leave optional fields and collections empty when you have no content.

You may ask your available Codex client to do this focused edit. Copy the prompt in CODEX-PROMPT.md and supply your project repository URL. If Codex cannot access that repository, paste the project's README or other public documentation into the chat. You can also edit the JSON yourself using MANUAL-EDITING.md.

Do not invent results, credentials, experience, testimonials or links. Do not upload private client data or secrets.

## 3. Publish

Commit the content changes. In your portfolio repository, open Settings > Pages. Under Build and deployment choose **Deploy from a branch**, select **main** and **/(root)**, then Save. Open the site URL shown on that Pages screen. This starter is plain HTML, CSS and JavaScript; it does not need a custom deployment workflow.

## 4. Check

Check your name, project link, images, Home/About/Projects/Contact navigation, dark/light theme switch, and phone layout. If you add Samples or Insights, check those pages and their links. Edit content/portfolio.json and commit again whenever you want to update the site.

CMS is optional and not active in this basic kit. Read CMS-LATER.md if you want it later.
